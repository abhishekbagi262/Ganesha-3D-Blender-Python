# Project Overview

## SHREE GANESHA — Procedural 3D Creation

A Blender scene created with Python scripting and the Blender Python API (`bpy`). The project explores procedural construction: creating a visual composition from reusable functions, geometric primitives, curves, materials and scene configuration.

## Project goals

1. Explore Blender's Python API for programmatic scene creation.
2. Break a complex subject into smaller, reusable modelling functions.
3. Practise 3D positioning, scaling, vector orientation and curve construction.
4. Apply named materials and configure lighting, camera and rendering.
5. Organise a multi-part scene into clearly logged build stages.

## Visual composition

The composition includes a seated Ganesha figure, four arms, a layered crown, throne, halo, dhoti, jewellery, lotus, modak and Mushika. A festival greeting is placed behind the figure.

## Technology

- **Blender** — 3D modelling, materials, lighting and rendering.
- **Python** — procedural scene orchestration.
- **bpy** — Blender's Python API.
- **mathutils** — vector and orientation calculations.

## Learning outcomes

The project demonstrates how reusable functions can simplify repetitive scene construction, how 3D objects can be positioned from coordinates and vectors, and how materials, lighting and camera configuration contribute to a coherent render.

## Running safely

The build script deletes existing objects in the active scene before constructing the model. Open a fresh Blender file or save a backup before running it. See the root README for execution instructions.
